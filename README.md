# yande.re 动漫图 · 实验版（洗牌袋）

> 测试仓库。正式版在 [a13609y/yandere-widget](https://github.com/a13609y/yandere-widget)，两个模块可同时装（模块名不同，存储键带 `lab_` 前缀，互不影响）。

## 装法

```
https://raw.githubusercontent.com/a13609y/yandere-widget-lab/main/lab.yaml
```

## 这一版解决什么

正式版「每次刷新实时请求一张」，素材走完就开始重复，而且重复是扎堆出现的。实验版换成 **shuffle bag（洗牌袋）**：

1. 一次向源站要**一页清单**（100 条元数据，**不下载图片**，1 个请求）；
2. 本地洗牌，之后每次刷新按洗好的顺序**发一张**（每次仍只下 1 张图）；
3. 一袋发完（默认 50 张）再补一袋，新袋剔掉看过的。

一袋之内绝不重复；袋与袋之间用「允许重复比例」控制重叠，重复被均匀撒开。

另外三件事：

- **按月切块**：每次装袋随机挑一个自然月（如 2024-03），只在这个月里取图 —— 时间分布均匀，不会老是最近那批；「最新」排序自动忽略此项。
- **两源轮换**：图源=自动时 Konachan / yande.re 交替（以前是 Konachan 用完才用 yande）。
- **md5 去重**：两站同一张画 md5 相同，去重键从 post id 换成 md5，跨站重复也能挡住。

## 参数（模块里「洗牌 · …」，在设置最上面）

| 参数 | 默认 | 说明 |
|---|---|---|
| 洗牌 · 每袋张数 | 50 | 一袋多少张，发完才换袋 |
| 洗牌 · 按月切块 | 开 | 每次装袋随机一个自然月；「最新」自动忽略 |
| 洗牌 · 允许重复比例 | 10 | 每次刷新有 10% 概率回放一张**最久没出现**的旧图（最近 8 次出现过的不会被回放） |
| 洗牌 · 同画师/变体去重 | 开 | 一袋里每个画师最多 1 张，跳过同一 pixiv 作品的多张与父子变体图 |

**防重复窗口写死 200**（不再暴露成变量）：洗牌袋模式下 200 足够，太大反而让袋子装不满。

## 推荐组合

| 排序 | 每袋 | 允许重复 | 按月切块 |
|---|---|---|---|
| 随机 | 50 | 10% | 开 |
| 热度 | 30 | 10% | 开 |
| 最新 | 50 | 10% | 关 |

## 与正式版相比精简掉的选项

- 过滤项只留 **露点 / 多格 / 白色**（其余七个删掉：命中率低、又容易把 q 级素材筛空；需要时用「自定义标签」临时补）。
- 四个尺寸画幅选择器合并成一个 **「画幅 · 尺寸适配」**：自动（小方/中横/大方/超大横）/ 全部方图 / 全部横图 / 全部竖图 / 不限。
- 防重复窗口变量删除（写死 200）。

## 实测

- 连续 8 次刷新：**2 个 API 请求**（装袋时合并了 2 页），袋 10 张，画师重复 0、连续重复 0。
- 为什么一袋只有 10 张：实测某个月里 20 条随机帖子有 **15 条是同一个画师**（批量投稿大户）。按月切块 + 每画师 1 张之后，一页只能留下几张，所以要合并 2~3 页才够装袋。
- 中号自动用横图（ar 1.78），大号自动用方图（ar 1.33）。
- 最新排序：不切月、正常出图；热度排序：按月切块正常。
