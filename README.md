# yande.re 动漫图 · 实验版（洗牌袋）

> 这是**测试仓库**，正式版在 [a13609y/yandere-widget](https://github.com/a13609y/yandere-widget)。两个模块可以同时装，互不影响（变量前缀不同、模块名不同）。

## 装法

Egern → 模块 → 右上角 + → 从 URL 导入：

```
https://raw.githubusercontent.com/a13609y/yandere-widget-lab/main/lab.yaml
```

装好后是「yande.re 动漫图 · 实验版」，和正式版可以并存。

## 这一版想解决什么

正式版是「每次刷新实时请求一张」，素材走完就开始重复，而且重复是扎堆出现的。实验版换成 **shuffle bag（洗牌袋）**：

1. 一次向源站要**一页清单**（100 条元数据，**不下载图片**，就 1 个请求）；
2. 本地洗牌，之后每次刷新按洗好的顺序**发一张**（每次还是只下 1 张图）；
3. 一袋发完（默认 50 张）再补一袋，新袋会剔掉看过的。

效果：**一袋之内绝不重复**，袋与袋之间用「允许重复比例」控制重叠，重复被均匀撒开，不会连着撞同一张。

另外，「图源 = 自动」时改成 **Konachan / yande.re 轮流**（以前是 Konachan 用完才用 yande），可用素材直接翻倍。

## 两个新参数（模块里叫「洗牌 · …」，在设置最上面）

| 参数 | 默认 | 说明 |
|---|---|---|
| 洗牌 · 每袋张数 | 50 | 一袋多少张。发完才换袋，50 = 每 50 次刷新换一袋 |
| 洗牌 · 允许重复比例 | 20 | 每次刷新有多大概率回放一张**最久没出现**的旧图。0 = 永不重复（素材见底时可能取不到图），20 = 十次里约两次 |

回放有保护：最近 8 次出现过的图不会被回放，所以不会“刚看完又看到”。

## 实测（默认配置）

连续 12 次刷新：**1 个 API 请求**，装袋 40 张，命中同一个月（2024-08）；其中 1 次是回放（相隔 10 次），连续重复 0 次。

## 推荐参数

| 排序 | 每袋 | 允许重复 | 防重复窗口 |
|---|---|---|---|
| 随机 | 50 | 10% | 200 |
| 热度 | 30 | 10% | 200 |
| 最新 | 50 | 10% | 100（按月切块关） |

## 与正式版的其它差异

- 无。所有正式版修过的 bug（yande 的 Referer、URL 编码、画幅 1.33 基准、白色过滤默认开、六年内/三年内时段、分级置顶等）都在。
- 唯一多出来的就是洗牌袋和两源轮询。
